# Design-of-microprocessor-based-medical-system
## Вывод по первому этапу

Была загружена запись №100 из MIT-BIH Arrhythmia Database и соответствующая экспертная разметка сердечных сокращений.

Из общего набора аннотаций выделены аннотации сокращений. На их основе рассчитаны RR-интервалы и мгновенная частота сердечных сокращений.

Сигнал был передискретизирован с 360 до 250 Гц, а положения аннотаций пересчитаны с сохранением их временных координат. По графикам подтверждено визуальное соответствие аннотаций QRS-комплексам до и после передискретизации.

Подготовленные данные сохранены для последующей реализации и оценки алгоритмов автоматического обнаружения QRS-комплексов.
